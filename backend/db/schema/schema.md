# Beacon — Database Schema

Tables are ordered by creation dependency: a table only appears after every table its foreign keys reference. Within the same dependency level, tables are grouped by what they belong to.

> **Note:** `resources` was defined twice in the source dump with identical DDL. Deduplicated to one definition below — verify your migration files don't actually have two separate `resources` tables with drift.

## Level 0 — No dependencies

### `users`
Auth-linked user record (Cognito-backed).

```sql
create table public.users (
  id serial not null,
  cognito_sub character varying(255) not null,
  email character varying(255) not null,
  name character varying(255) null,
  created_at timestamp without time zone null default now(),
  updated_at timestamp without time zone null default now(),
  last_login_at timestamp without time zone null,
  constraint users_pkey primary key (id),
  constraint users_cognito_sub_key unique (cognito_sub),
  constraint users_email_key unique (email)
) TABLESPACE pg_default;
```

### `hackathons`
Core hackathon listing entity — nearly everything else hangs off this.

```sql
create table public.hackathons (
  id bigint generated by default as identity not null,
  external_id bigint null,
  title character varying null,
  description character varying null,
  college_name character varying null,
  team_size json null,
  mode character varying null,
  is_paid boolean null,
  url character varying null,
  start_date date null,
  deadline date null,
  created_at timestamp without time zone null default now(),
  prizes json null,
  constraint hackathons_pkey primary key (id),
  constraint hackathons_url_unique unique (url)
) TABLESPACE pg_default;
```

### `jobs`
Async job queue (analysis / assets / scrape). `result_id` is a plain int column — no FK constraint declared, so it doesn't create an ordering dependency.

```sql
create table public.jobs (
  id serial not null,
  job_type character varying(50) not null,
  payload jsonb not null,
  status character varying(50) not null default 'queued'::character varying,
  result_id integer null,
  error_message text null,
  retry_count integer null default 0,
  created_at timestamp without time zone null default CURRENT_TIMESTAMP,
  updated_at timestamp without time zone null default CURRENT_TIMESTAMP,
  constraint jobs_pkey primary key (id),
  constraint jobs_job_type_check check (
    (job_type)::text = any (
      (array['analysis'::character varying, 'assets'::character varying, 'scrape'::character varying])::text[]
    )
  ),
  constraint jobs_status_check check (
    (status)::text = any (
      (array['queued'::character varying, 'processing'::character varying, 'completed'::character varying, 'failed'::character varying])::text[]
    )
  )
) TABLESPACE pg_default;

create index IF not exists idx_jobs_status on public.jobs using btree (status) TABLESPACE pg_default;
create index IF not exists idx_jobs_job_type on public.jobs using btree (job_type) TABLESPACE pg_default;
create index IF not exists idx_jobs_created_at on public.jobs using btree (created_at desc) TABLESPACE pg_default;
create index IF not exists idx_jobs_result_id on public.jobs using btree (result_id) TABLESPACE pg_default;

create trigger update_jobs_updated_at BEFORE
update on jobs for EACH row
execute FUNCTION update_updated_at_column ();
```

> Requires `update_updated_at_column()` to already exist as a function before this trigger is created.

### `applications`
Standalone waitlist / feature-request submissions. Fully decoupled from the rest of the schema.

```sql
create table public.applications (
  id uuid not null default gen_random_uuid (),
  email character varying(255) not null default ''::character varying,
  feature_request text not null default ''::text,
  created_at timestamp with time zone null default now(),
  constraint applications_pkey primary key (id)
) TABLESPACE pg_default;
```
